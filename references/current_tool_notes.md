# Official tool notes checked 13 September 2026

These notes support the design, not a claim that the owner's installation/account has been tested. Recheck capabilities and prices at execution time. All URLs below are official provider documentation.

## Codex instructions and desktop control
Codex documents AGENTS.md discovery; ordinary Markdown files do not all become automatic instructions, so AGENTS.md points to the stage guides.
Source: https://developers.openai.com/codex/guides/agents-md

OpenAI documents Computer Use for desktop applications on macOS and Windows, subject to workspace controls. Check actual local capability.
Source: https://help.openai.com/en/articles/20001510-manage-browser-and-computer-use-in-your-enterprise-workspace

Record & Replay is documented for eligible macOS users with Computer Use, with regional restrictions. It is an optional way to capture stable workflows, not a required dependency.
Source: https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan

## CapCut
CapCut documents desktop SRT/TXT import and editable caption blocks. Nonstandard formatting can fail. Verify menus and styles in the installed version.
Source: https://www.capcut.com/help/how-to-import-subtitles

## Local editorial rendering
FFmpeg documents zoompan and other filters that can build camera motion and predictable draft renders without an AI video model. Layered parallax still requires separate layers/masks.
Source: https://ffmpeg.org/ffmpeg-filters.html#zoompan

## Kling
The official VIDEO 3.0 guide documents image-to-video, start/end-frame support and flexible durations. It does not validate the uploaded plan's old credit quote. Feature combinations must be checked in the selected route.
Source: https://kling.ai/quickstart/klingai-video-3-model-user-guide

## Google
Flow's official feature matrix distinguishes first-frame, first+last-frame and reference-image capabilities by model. Prefer a verified filmmaking route for controlled shots rather than assuming a generic chat video button has every control.
Source: https://support.google.com/flow/answer/16352836?hl=en

The Gemini API Veo documentation describes last-frame constraints, model-dependent durations and reference images. It also documents adult-only personGeneration values for image-conditioned routes and regional limits. Child-character support is NOT assumed. Generated audio is listed as always on for certain Veo models; mute/discard it in the edit rather than promising a universal generation-time off switch.
Source: https://ai.google.dev/gemini-api/docs/veo

Gemini API uses Cloud Billing. Some subscription-linked AI Studio benefits exist, but they are not a blanket promise of free external API video generation. Check the exact entitlement before spending.
Sources: https://ai.google.dev/gemini-api/docs/billing
https://blog.google/innovation-and-ai/technology/developers-tools/google-one-ai-studio/

## Publishing rights
Verify rights for the specific Suno song and retain the relevant license/subscription records. Suno's current help pages should be checked rather than assuming account status alone resolves every song's rights.
Sources: https://help.suno.com/en/articles/9601665
https://help.suno.com/en/articles/2410177

Review YouTube's audience guidance before publishing children's songs.
Source: https://support.google.com/youtube/answer/9528076?hl=en
