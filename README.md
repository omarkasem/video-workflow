# Adam & Deema - Storyboard-First Starter Kit

Version 0.1 | Prepared 13 September 2026

## What this is
A proposed production workflow and small Codex instruction set tailored to the uploaded song, characters, and old plans. It is not an installed CapCut integration, a tested one-click automation, a rendered storyboard, or a finished video. No image/video generation has been purchased or performed.

The source song and character images are included as unchanged copies under simple portable filenames. The original archive is untouched. The old plans are retained only in sources/legacy/.

## The everyday workflow
Song + references -> rough storyboard sheets -> full-song animatic -> approve -> high-quality individual frames -> approve -> a few generated motions -> CapCut -> review/export.

The owner should normally review pictures and a preview video, not edit configuration files. Codex maintains the shot data and progress behind the scenes.

## Files that matter
- AGENTS.md: the entry point, approval rules, and resume behavior.
- guides/01_creative_workflow.md: the visual planning process and proposed channel rules.
- guides/02_asset_production.md: stills, videos, references, interchangeable providers, budgets.
- guides/03_capcut_assembly.md: a small pilot and reliable editor assembly.
- project/project.json: this episode's proposed settings and eight draft chapter ranges.
- project/state.json: nothing is approved for production yet.
- project/caption_timing_audit.md: issues found in the existing files.
- project/lyrics_DRAFT_normalized.srt: importable-format candidate; timing is UNVERIFIED.
- project/shots.example.json: a schema example, not an executable full timeline.
- references/current_tool_notes.md: official sources and capability caveats.

## How to start on the production laptop
Open this folder as the local project in the desktop agent. Ensure the folder is accessible on that device. Use:

> Read AGENTS.md and inspect the source assets. Stay in planning mode. Do not generate high-quality images or paid videos. First help verify the lyric timing, then propose one rough storyboard sheet to establish the review format. Stop for approval before producing the remaining sheets.

Once the review format is accepted:

> Complete all rough storyboard sheets and prepare a full-length animatic using the approved rough panels, the original song, and draft lyric captions. Keep shot IDs visible in the review version. Stop before high-quality production.

Later, after explicit visual approval:

> Resume from project/state.json. Prepare only the approved high-quality frames. Show a contact sheet and flag any changes from the storyboard. Do not spend video credits yet.

The final generation request should name the approved shots, provider route, maximum spend, and retry budget. Ask Codex to summarize those before execution.

## Important limits
The eight board ranges are draft editorial groupings using the supplied captions, not a listening-verified cut list. No clip pricing, paid account access, Gemini child-character support, CapCut UI behavior, or provider output quality has been tested in the owner's accounts. These checks are required before production.
