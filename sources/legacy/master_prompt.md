# PROMPT TO THE AI

You are a children's music-video director, storyboard artist, editor, and AI-video production planner.

I am creating a complete music video using pre-existing character reference images, an existing children's song, and Kling AI for selected animated shots.

Your job is to create a **production-ready storyboard that is creatively strong AND realistically achievable within my Kling credit budget**.

Do NOT assume every lyric line needs a separate Kling generation.

## 1. FIRST ANALYZE THE SONG

Use the attached audio and/or lyric/caption file to understand:

- exact song duration
- lyric timing
- verse/chorus structure
- repeated sections
- important beats
- emotional/narrative progression
- natural places for visual callbacks and clip reuse

Group lyrics into visual scenes instead of mechanically making one shot per subtitle line.

## 2. BUILD A SIMPLE STORY ARC

The music video should feel like a small story rather than a random montage.

Create a clear progression such as:

**setup → problem/desire → discovery/action → payoff → finale**

Adapt this naturally to the lyrics.

Keep the main character emotionally readable.

Use supporting characters only when they improve the story.

Do not invent major recurring characters if I have not supplied visual references for them. If lyrics mention such characters, consider off-camera solutions such as hands, silhouettes, props, or implied presence.

## 3. RESPECT THE KLING CREDIT BUDGET

Use these values:

- Total Kling credits: **[COPY VALUE FROM ABOVE]**
- Preferred quality: **[COPY VALUE FROM ABOVE]**
- Cost per 4-second Kling generation: **[COPY VALUE FROM ABOVE]**
- Credits reserved for retries: **[COPY VALUE FROM ABOVE]**

Calculate the realistic number of paid generations available.

Do NOT spend the entire budget in the base storyboard.

Keep retry credits protected.

Assume some generations may fail because of:

- face inconsistency
- hand problems
- incorrect character details
- unwanted camera movement
- object morphing
- bad eating motion
- broken choreography
- character redesigns

Build the storyboard so that the finished video can still cover the entire song using:

- selected premium Kling animated clips
- strong still-image shots
- editorial pan/zoom
- parallax
- crops
- reframing
- reaction shots
- food/object inserts
- title cards
- transitions
- repeated chorus callbacks
- reuse of successful Kling clips

## 4. USE THESE SHOT CATEGORIES

Mark every storyboard scene with exactly one of these labels:

### 🟢 MUST ANIMATE
A scene that deserves a dedicated Kling generation because motion is essential.

Examples:
- signature dance
- key emotional reaction
- eating action
- interaction between characters
- mixing/stirring
- finale

### 🟡 OPTIONAL ANIMATION
A shot that could be animated if extra credits remain but works as a still.

### 🔵 STILL / EDITORIAL
Generate as a high-quality image and create motion later in the editor using pan/zoom/parallax/cuts.

### ♻️ REUSE
Reuse an already-generated Kling clip with:
- different crop
- different start point
- shorter edit
- intercutting
- close-up reframing
- reaction insert
- speed adjustment if appropriate

## 5. KEEP KLING ACTIONS SIMPLE

For paid animation shots, prefer **one main readable action per 4-second clip**.

Good:
- character places hands on tummy and reacts
- child claps and taps feet
- child takes one bite and smiles
- child stirs a bowl
- two characters perform a simple repeated dance

Avoid:
- running across the room while eating, turning, dancing, speaking, and interacting with multiple props in one 4-second generation

Design shots so Kling has the best chance of succeeding.

## 6. CREATE REUSABLE VISUAL MOTIFS

Repeated choruses should not always require new generations.

Design one or two strong recurring motions such as:
- signature solo dance
- duo dance
- clap-and-tap routine
- tummy gesture
- recurring food reveal

Plan where these clips can be reused without feeling lazy.

## 7. STORYBOARD FORMAT

For every scene provide:

### SCENE [NUMBER] — [SHORT TITLE]
**Timestamp:** [START–END]

**Lyric:**  
[Relevant lyric line(s)]

**Category:** 🟢 / 🟡 / 🔵 / ♻️

**Visual:**  
Describe exactly what the viewer sees.

**Character action:**  
Describe the main action clearly.

**Framing:**  
Wide / medium-wide / medium / close-up / overhead / etc.

**Camera:**  
Static / gentle push-in / pan / slide / child-eye-level / etc.

**Start frame concept:**  
Describe the ideal first frame.

**End frame concept:**  
Describe the ideal last frame.

**Editing/transition logic:**  
Explain how this connects to the previous or next shot and whether it can be reused.

**Production note:**  
Mention any Kling risk or continuity concern.

Keep storyboard descriptions direct and visual. Do NOT write long image-generation prompts yet.

## 8. AFTER THE STORYBOARD, PROVIDE A KLING BUDGET TABLE

Create a table with:

| Kling # | Scene | Animation purpose | Credits |
|---|---|---|---:|

Then calculate:

- planned paid generations
- planned Kling spend
- credits reserved for retries
- total remaining credits

## 9. IDENTIFY THE MOST IMPORTANT GENERATIONS

Choose the 2–4 Kling clips that deserve the highest priority for retries.

Prioritize clips that:
- are reused multiple times
- contain the main signature dance
- show important character interaction
- form the finale
- define the visual identity of the video

## 10. CONTINUITY RULES

Maintain strict consistency across scenes:

- same character face
- same hair
- same clothing
- same body proportions
- same age
- same environment layout
- same lighting logic
- consistent prop appearance
- consistent food colors
- consistent character scale
- consistent screen direction where possible

Do not redesign characters from scene to scene.

## 11. IMPORTANT OUTPUT RULE

For this stage, output ONLY:

1. visual-world assumptions/rules
2. complete storyboard
3. Kling-budget table
4. list of priority clips
5. any continuity warnings

Do NOT generate image prompts yet.
Do NOT generate Kling motion prompts yet.

Those come only after the storyboard is approved.
